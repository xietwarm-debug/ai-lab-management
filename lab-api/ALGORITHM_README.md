# 文本相似度算法模块使用说明

## 📋 功能概述

本模块实现了基于 **TF-IDF + 余弦相似度** 的中文文本查重算法，用于作业批改场景中的抄袭检测。

## 🔧 技术栈

- **jieba**: 中文分词库
- **scikit-learn**: TF-IDF向量化和余弦相似度计算

## 📦 安装依赖

```bash
cd lab-api
pip install -r requirements.txt
```

## 🚀 快速开始

### 1. 基本用法

```python
from modular.algorithm_nlp import calculate_text_similarity

# 计算两段文本的相似度
text1 = "学生提交的作业内容..."
text2 = "参考答案或其他学生作业..."

similarity = calculate_text_similarity(text1, text2)
print(f"相似度：{similarity}%")  # 输出: 相似度：85.23%
```

### 2. 批量比对

```python
from modular.algorithm_nlp import calculate_multi_text_similarity

reference = "标准答案"
candidates = ["学生A的作业", "学生B的作业", "学生C的作业"]

results = calculate_multi_text_similarity(reference, candidates)
# 返回按相似度降序排列的结果列表
for result in results:
    print(f"索引 {result['text_index']}: {result['similarity']}%")
```

## 📊 算法原理

### TF-IDF（词频-逆文档频率）

1. **分词**：使用jieba将中文文本切分为词语
   - "人工智能很重要" → "人工智能 很 重要"

2. **TF（词频）**：词语在文档中出现的频率
   
3. **IDF（逆文档频率）**：衡量词语的稀有程度
   - 常见词（如"的"、"是"）IDF值低
   - 罕见词（如"卷积神经网络"）IDF值高

4. **TF-IDF** = TF × IDF

### 余弦相似度

将两段文本转化为向量后，计算它们夹角的余弦值：
- **1.0**：完全相同
- **0.0**：完全不同
- **0.0-1.0**：相似度程度

## ⚠️ 注意事项

1. **性能考虑**：
   - 单次比对耗时约 50-200ms
   - 建议限制比对数量（当前限制为5个其他学生作业）

2. **准确性局限**：
   - 基于关键词匹配，无法识别语义改写
   - 短文本（<50字符）准确度较低
   - 专业术语较多的文本效果更好

3. **误报处理**：
   - 查重率高 ≠ 一定抄袭（可能是引用标准答案）
   - 建议结合人工判断
   - 系统仅提供参考，最终决定权在教师

## 🆘 故障排查

### 问题1：导入错误 `ModuleNotFoundError: No module named 'jieba'`

**解决**：
```bash
pip install jieba scikit-learn
```

### 问题2：查重率始终为0

**可能原因**：
- 文本过短（<50字符）
- 文件解析失败（非文本格式）
- 没有其他学生作业可供比对

**检查方法**：
查看返回的 `limitations` 字段，会说明未进行查重的原因。

### 问题3：查重率异常高（>95%）

**可能原因**：
- 两份作业确实完全相同
- 都引用了相同的标准答案
- 文本太短导致偶然匹配

**建议**：结合 `risks` 和 `signals` 字段综合判断。
